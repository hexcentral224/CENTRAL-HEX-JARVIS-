## Fonctionnalités

- Interface web futuriste.
- Conversation avec une IA via un serveur sécurisé.
- Déploiement prévu sur Netlify et Render.
- Évolutions futures : voix et intégration Android.

## Technologies

- HTML, CSS, JavaScript
- Node.js
- OpenAI API
- Netlify et Render

## Configuration

Ajoute la clé `OPENAI_API_KEY` dans les variables d’environnement du serveur Render.

**Ne mets jamais ta clé API dans le frontend ni dans un dépôt public.**
